# Web server

Scripts to set up and configure the Nginx web server on web-01.

| File | What it does |
| --- | --- |
| 0-transfer_file | Sends a file to a server with scp |
| 1-install_nginx_web_server | Installs Nginx and serves "Holberton School" on port 80 |
| 2-setup_a_domain_name | Holds the domain name pointing to web-01 |
| 3-redirection | Adds a 301 redirect on /redirect_me |
| 4-not_found_page_404 | Adds a custom 404 page |
| 5-design_a_beautiful_404_page.html | A designed 404 page |
